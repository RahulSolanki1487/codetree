# codetree-skill (working name)

A Claude Code skill that turns any codebase into one HTML file you can open in the browser: tiles for the main areas, the classes or files in each, and their functions and methods, with descriptions and one search box. A second step fills in missing descriptions, as a diff you review.

**Status: planning.** Nothing is built yet. Read [docs/plan.md](docs/plan.md).
